每日程式解題練習的紀錄倉庫，收錄 LeetCode、Codeforces 等平台的題目解法與思路整理，以練代學、累積資料結構與演算法的實作經驗。

## 狀態

> **持續更新中**：解法與筆記將隨每日練習陸續補上。

## 內容規劃

| 類別 | 說明 |
|------|------|
| 每日解題 | 每日一題的解法與複雜度分析 |
| 資料結構 | 陣列、鏈結串列、樹、堆積、圖等實作 |
| 經典演算法 | 動態規劃、貪婪、雙指標、回溯、圖論 |
| 平台整理 | LeetCode / Codeforces 題目分類索引 |

## 解題格式

每個題目以統一模板記錄：

- 題目連結與難度
- 解題思路（含時間 / 空間複雜度）
- 程式碼實作（C++ / Python）
- 反思與可改進方向

## 目錄結構

```
daily-coding-challenges/
├── leetcode/       # LeetCode 題解
├── codeforces/     # Codeforces 題解
├── notes/          # 演算法筆記
└── README.md
```
